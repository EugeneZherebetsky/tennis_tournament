# Analysis and proposed improvements

## What works well
- Single self-contained file, no dependencies, works offline once loaded.
- Correct round-robin: all 10 pairs, each player plays 4 and rests once.
- Graceful no-JS fallback (static schedule + manual standings table).
- Safe DOM updates (`textContent`, no `innerHTML`) – no XSS via names.
- Mobile layout is fine at 375 px (no horizontal scroll); print/PDF styles.
- Clear rules incl. a sensible time-limit rule for an 8-minute slot.

## Status
Done: bugs 1–7, round timer, offline/PWA, 11/21-point format.

## Bugs / weak spots (verified in a headless browser)
| # | Issue | Fix |
|---|-------|-----|
| 1 | `1e1` is accepted as 10 (`type=number` allows `e`). | Accept only `/^\d{1,2}$/`. |
| 2 | Implausible scores accepted (`40:2`, `11:10` with no context). | Soft warning: winner > 11 must lead by exactly 2; ask "time limit?" for non-11 results. |
| 3 | Tie-break ignores head-to-head. With 1 point per win and 5 players, two-way ties are very common; ITTF practice is head-to-head first. | Order: wins → head-to-head (among tied) → point diff → points scored. |
| 4 | Rule 4 needs an 8-minute limit but the page has no timer; the resting player must use another device. | Built-in round timer (start/pause, 8:00 + 2:00 changeover, beep/vibrate, Screen Wake Lock so the phone doesn't sleep). |
| 5 | Saved state is only loosely validated (names/scores types not checked). | Coerce to strings on load; version the storage key. |
| 6 | Inline `onclick` + inline script block a strict Content-Security-Policy on your domain. | Move JS/CSS to files, use `addEventListener`. |
| 7 | Header metrics/texts are hard-coded to 5 players / 2 tables. | Derive from config. |

## Feature proposals (by value for a hosted version)
1. **Configurable format** – 3–8 players, 1–3 tables, match length; schedule
   generated by the circle method, with rest rotation balanced.
2. **Round timer** (see #4) with "current round" highlight and auto-scroll.
3. **Share results without a backend** – encode the state in the URL hash
   (`#d=...`) + "Copy link"/QR code so other phones can view/continue.
4. **Live shared scoreboard (optional backend)** – e.g. Supabase table +
   realtime subscription: one organiser edits, everyone watches on their phone.
5. **PWA** – `manifest.json` + service worker: "Add to home screen", works
   without signal in a gym.
6. **History & export** – keep past tournaments, export CSV / share image of
   the final table; undo for "reset scores".
7. **Head-to-head matrix** (5×5 grid) in addition to the standings.
8. **i18n** – RU/EN toggle; dark mode (`prefers-color-scheme`).
9. **Hosting polish** – favicon, Open Graph tags, `<meta name=description>`,
   CSP via `<meta http-equiv>` or host headers, analytics-free.

## Suggested order
Quick wins (1, 3, 5, 6 from the bug list) → timer → URL sharing + PWA →
configurable format → optional realtime backend.
