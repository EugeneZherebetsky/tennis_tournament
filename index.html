          Легенда таблицы

          И — сыгранные матчи; В — победы; П — поражения; О+ — набранные очки; О− — пропущенные очки; Δ — разница очков (О+ минус О−); Б — турнирные баллы (1 за победу, 0 за поражение). Порядок мест: баллы → личные встречи среди равных → Δ → О+. «=» у места означает равенство показателей.

          Правила турнира
          1. Каждый играет с каждым один раз. Никто не выбывает. Свободные в этом раунде игроки указаны в расписании.
          2. Матч состоит из одной партии до 11 очков. Для обычной победы нужен перевес минимум в два очка (например, 11:9 или 13:11).
          3. Первую подачу определите жребием. Подача меняется через каждые два розыгрыша, при 10:10 — после каждого. При подаче мяч подбрасывают с открытой ладони и он должен отскочить сначала на своей, затем на чужой половине стола.
          4. Лимит — 8 минут на матч. По сигналу завершите текущий розыгрыш. Если партия не закончена, выигрывает тот, кто ведёт в счёте. При равенстве разыгрывается одно решающее очко по очереди подачи. Затем внесите итоговый счёт. Это специальное правило мини-турнира, а не стандартное правило настольного тенниса.
          5. Таймер подаёт сигнал за минуту до конца игры и по её окончании. После игры в каждом раунде — две минуты на запись результатов и смену игроков.
          6. За победу начисляется 1 турнирный балл, за поражение — 0. Места определяются по баллам. При равенстве баллов — по результатам личных встреч между равными участниками, затем по общей разнице очков, затем по общим набранным очкам. Если все показатели равны, место делится; если нужен единственный победитель, участники могут разыграть дополнительное решающее очко в оставшееся время.
          7. Последние 5 минут — проверка результатов и объявление победителя. Финальный матч не предусмотрен: победитель определяется по итогам кругового турнира.
